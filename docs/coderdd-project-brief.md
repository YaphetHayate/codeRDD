CodeRDD

项目介绍： CodeRDD 是一套基于 SDD（规范驱动开发）理念的 AI 原生化软件开发工作流系统。它将 Vibe Coding 拆解为"定义 → 设计 → 实现 → 验证 → 评价 → 呈现"六个标准化阶段，每个阶段由专属 AI 角色（PM/CTO/UX/DEV/QA/EVAL/PSE）独立执行，并增设 AUDITOR 事前审视与 PLANNER 规划者，承担阶段间的独立把关与长程任务编排。角色职责与协作协议经 SKILL.md 标准化定义，由 rdd-engine 能力总线串联为"阶段可审视、交付可回溯、质量可复现"的工程化流水线。项目提供桌面应用增强套件，平台支持接入 Opencode、Claude Code 等 Agent，灵活搭配不同 LLM 与角色实现多 AI 协作，有效利用各模型特性匹配不同需求场景，构建成本可控、质量可靠的 Agent 研发团队。

技术栈： Agent，Subagent，Opencode，Claude Code，DSH 插件，Skill，Plan-and-Execute 树形编排，CLI 能力总线

背景： 深入实践 Vibe Coding 过程中，面临四大核心痛点：意图偏差：LLM 对需求理解错误，生成代码偏离预期，隐含共识无法追溯，返工往往从头开始；质量不可控：生成代码参差不齐，缺乏标准化验收，测试常由同一模型基于已有实现编写，等于自己给自己判卷；上下文溢出：长对话超出窗口限制，早期信息被挤掉，上游噪音持续污染下游；重复消耗：多模型、多会话之间缺乏知识共享，相同代码需反复理解，Token 与时间浪费严重。现有 AI 辅助开发呈现"作坊式"状态，缺乏工程化管理手段。

目标： 打造一套轻量、可移植、平台无关的 AI 开发工作流框架，让任何团队都能将 AI 辅助开发纳入工程化管理，实现阶段可审视、交付可回溯、质量可复现；通过环节独立设计，实现不同 LLM 与 Agent 灵活搭配，构建适配多元场景的智能开发团队。

行动：
• 基于 Plan-and-Execute 范式设计八角色（PM/CTO/UX/DEV/QA/EVAL/AUDITOR/PSE）与规划者 Agent 体系，以 SKILL.md 标准化定义各角色职责边界与协作协议；用阶段角色白名单机械约束流转，杜绝跨阶段越权，并落地"需求确认—拆解"双门、测试先行，以及事前审视、独立测试、事后复盘三权分立的验收结构。
• 实现 rdd-engine 能力总线，提供跨角色、跨会话复用的代码探索缓存，阶段流转与最小交接包，长程任务的目标树编排，以及确定性质量度量与四层机械门禁，使上下文裁剪与质量控制从"要求模型自觉"变为"由机制保证"。

成果：
• 需求澄清与技术实现解耦：需求无歧义、方案明确后才进入开发，避免模型认知偏差导致的无效返工；测试独立于设计，严格按需求文档的验收标准生成用例，杜绝模型基于已有实现"自圆其说"的无效验收。
• 探索结果零成本复用、上下文纯净可控：任一角色探索过的代码，其余角色与后续会话均可直接命中复用，显著减少重复理解开销；阶段切换强制以新会话承载交接，只传最小上下文，上游污染下游在机制上不可能发生。
• 长程任务不失控、质量可复现：多轮"派发—回写—再规划"由持久化状态机承载，预算有上限、中断可续跑、节点不重复消费、终局必出结案报告；量化门禁由工具确定性执行，验收结论可追溯、可复现，项目自身即以此流程开发。
