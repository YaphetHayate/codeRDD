# 图片/素材生成能力补充

- **描述**：补充专业绘图/素材生成能力，覆盖图标、装饰图、插画等通用素材。不绑定到 UX 角色，作为独立工具或服务供所有需要素材的角色调用（UX 出效果图、前端 DEV 出页面素材等）。

- **验收标准**：
  1. 存在独立的图片/素材生成 skill 或工具，不挂在 RDD-UX 下
  2. UX 可调用该能力生成参考效果图
  3. 前端 DEV 可调用该能力生成页面所需素材（icon、插图等）
  4. 已有 pixel-art-sprites 保持独立，新素材能力覆盖像素画之外的通用风格

- **优先级**：中
- **来源细节**：用户明确反馈"项目前端素材一直很丑"，缺乏系统化的素材生成手段

- **影响范围**：新增 skill/工具定义，UX 和 DEV skill 中增加该工具的调用指引
- **边界与异常**：
  - 不与 pixel-art-sprites 合并，二者覆盖不同风格域
  - 素材质量取决于底层 AI 图片生成模型能力，需在实现前评估可用模型
  - 若无可用的高质量图片生成模型，可降级为 SVG 代码生成方案
