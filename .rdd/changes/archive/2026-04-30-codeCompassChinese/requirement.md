# code-compass 生成产物默认中文

## 背景

code-compass 技能生成的 `map.md`（代码全景图）和 `README.md` 实际输出为英文，即使技能参考文件中包含中文模板和中文职责推测表，LLM 在执行时仍然倾向于生成英文内容。需要将两个子功能的语言策略统一为：始终使用中文。

## 需求列表

### 需求 1：README 生成器默认中文输出

- **描述**：修改 `references/readme-generator/readme-generator.md` 中的语言策略，将当前的"根据项目注释语言智能判断"改为"始终使用中文生成 README"，移除语言判断逻辑。
- **验收标准**：readme-generator.md 中不再包含英文输出或语言判断的指令，明确要求所有内容（标题、描述、说明、注释）使用中文。
- **优先级**：高
- **影响范围**：`references/readme-generator/readme-generator.md`

### 需求 2：代码全景图默认中文输出

- **描述**：在 `references/map/map.md` 中新增语言策略章节，明确要求生成的全景图所有内容使用中文，包括职责推测、方法说明、提示信息等。
- **验收标准**：map.md 中包含明确的中文输出指令，生成的 `.code-compass/map.md` 中所有描述性文本为中文。
- **优先级**：高
- **影响范围**：`references/map/map.md`

## 关键约束

- 仅修改两个参考文件中的语言策略，不改变功能逻辑和输出结构
- 方法签名、代码片段等技术内容保持原始语言不变（如函数名、参数名、代码示例）

## 讨论记录

- 用户反馈：实际使用中 map 和 readme 都生成为英文
- 确认策略：默认中文，不询问是否需要英文版，无论项目代码语言如何
- 技术内容（函数名、签名等）保持原文，不做翻译
