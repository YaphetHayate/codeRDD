# Bug Register 模板

> 开发过程中发现的非阻塞 bug。PM 可定期审视排优先级，DEV 可批量处理。

| ID | 发现日期 | 描述 | 发现上下文 | 状态 | 优先级 |
|----|---------|------|-----------|------|--------|
| B001 | YYYY-MM-DD | [简述问题现象和影响] | [在哪个 Task/模式下发现] | ⬜ 待处理 | 高/中/低 |

## 状态说明

- ⬜ 待处理：已记录，等待 PM 评估或 DEV 处理
- 🔄 处理中：已纳入当前修复任务
- ✅ 已修复：修复完成并验证通过

## 优先级指南

- **高**：影响核心功能、用户高频操作、数据正确性
- **中**：影响非核心功能、有临时规避方案
- **低**：显示瑕疵、边缘场景、体验优化

## 写入时机

DEV 在 Mode 1/2/3 中发现不阻塞当前任务的 bug 时，追加一行，继续当前工作。

## 处理时机

- 当前任务全部完成后，DEV 检查 register 中是否有待处理的 bug，向用户确认是否继续修复
- PM 审视归档时可以扫描 register，将有价值的 bug 纳入下一轮需求
- 用户随时可以指定"修一下 B001"触发 Bug 修复模式
