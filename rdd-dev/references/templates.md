# 模板集合

> 本文档是 [SKILL.md](../SKILL.md) 的补充材料，包含验证报告、完成汇报的呈现格式模板（提交规范已移交 QA，见 QA 的 `qa-workflow.md#第六步`）。

## 验证报告格式

```
验证报告：

┌──────────────────┬──────────┬─────────────────────┐
│ 检查项             │ 结果     │ 备注                 │
├──────────────────┼──────────┼─────────────────────┤
│ Lint              │ ✅ 通过  │                     │
│ TypeCheck         │ ✅ 通过  │                     │
│ 单元测试          │ ✅ 通过  │ 12/12 passed        │
│ 构建              │ ✅ 通过  │                     │
└──────────────────┴──────────┴─────────────────────┘
```

## QA 测试报告格式

```
QA 测试报告：

┌──────────────────┬──────────┬──────────┬──────────┬──────────────────────┐
│  测试文件          │ 总数      │ 通过      │ 失败      │ 失败用例               │
├──────────────────┼──────────┼──────────┼──────────┼──────────────────────┤
│  user.test.ts     │ 8        │ 7        │ 1        │ TC-005: 边界校验缺失   │
│  search.test.ts   │ 6        │ 6        │ 0        │                      │
└──────────────────┴──────────┴──────────┴──────────┴──────────────────────┘

通过率：13/14 (92.9%)
```

## 完成汇报格式

DEV 不再执行提交（移交 QA）。完成自测后向用户汇报并推进路由至 QA：

```
开发完成，自测通过：

┌──────────────────┬──────────┬─────────────────────┐
│ 检查项             │ 结果     │ 备注                 │
├──────────────────┼──────────┼─────────────────────┤
│ Lint              │ ✅ 通过  │                     │
│ TypeCheck         │ ✅ 通过  │                     │
│ 单元测试          │ ✅ 通过  │ 12/12 passed        │
│ 构建              │ ✅ 通过  │                     │
└──────────────────┴──────────┴─────────────────────┘

路由已推进至 QA，由 QA 执行功能验收 + 代码质量检查 + 提交门禁。
```

## 更新流转状态

开发完成的 task，在新格式路由总览中将对应行 `当前责任人` 从 `DEV` 改为 `QA`（或在用户明确跳过 QA 时标注完成/跳过原因），并在备注中写明验证结果。若存在关联设计文档，同步将设计文档 `## 流转控制 > 当前责任人` 改为 `QA`；若无设计文档，同步更新需求文档。旧格式归档才回退为将 DEV 列从 ⬜ 更新为 ✅。

> 分支管理仍由 DEV 负责（创建分支、在其上工作）；`git commit` 由 QA 在提交门禁通过后执行，规范见 QA 的 `qa-workflow.md#第六步`。
