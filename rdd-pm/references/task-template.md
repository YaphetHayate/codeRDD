# Task 模板

## 归档目录结构

```
.rdd/
└── changes/
    └── archive/
        └── YYYY-MM-DD-需求简称/            ← PM 创建
            ├── task.md                     ← PM 创建并维护（跟踪索引）
            ├── pm/                         ← PM 写入
            │   ├── overview.md             ← 需求总览
            │   └── {需求文件名}.md         ← 独立需求文件
            ├── cto/                        ← CTO 写入
            │   └── {需求文件名}.md         ← 设计方案，与 pm/ 文件名对齐
            ├── ux/                         ← UX 写入
            │   └── {需求文件名}.md         ← 设计规格，与 pm/ 文件名对齐
            ├── tests/                      ← QA 写入
            │   └── test-cases.md           ← 测试用例文档
            └── eval/                       ← EVAL 写入
                └── evaluation-report.md    ← 验收评价报告
```

> 各角色只在各自的子目录写入，`task.md` 由各角色更新对应列状态。

## 文件格式

```markdown

> 状态说明：✅ 完成 | ⬜ 待开始 | ⏭️ 跳过 | 🔄 进行中

## 角色参与计划

| 角色 | 参与状态 | 理由 |
|------|---------|------|
| CTO | 参与/跳过 | [简要说明] |
| UX | 参与/跳过 | [简要说明] |
| DEV | 参与/跳过 | [简要说明] |
| QA | 参与/跳过 | [简要说明] |

## 总览

| Task | 优先级 | PM | CTO | UX | DEV | QA |
|------|--------|----|-----|----|-----|----|
| 1. [需求标题] | [优先级] | ✅ | ⬜ | ⬜ | ⬜ | ⬜ |
| 2. [需求标题] | [优先级] | ✅ | ⬜ | ⬜ | ⬜ | ⬜ |

## Task 1: [需求标题]

- **需求来源**：pm/overview.md > 需求 1
- **PM 需求文件**：pm/[name].md

- **PM**：✅
- **CTO**：⬜
- **UX**：⬜
- **DEV**：⬜

...
```

## PM 归档填写规则

- `task.md` 只是需求跟踪索引，不替代 PM 需求文档；需求细节、场景、约束、验收标准必须保留在对应 `pm/*.md` 中
- PM 归档时必须填写"角色参与计划"表格，声明每个角色（CTO/UX/DEV/QA）是否`参与`或`跳过`及简要理由
- 角色参与计划不使用 ✅/⬜/⏭️，避免和 Task 执行状态混淆
- 角色参与计划与 Task 详情列保持一致：计划中 `跳过` 的角色，所有 Task 该列应为 ⏭️；计划中 `参与` 的角色，所有 Task 该列初始为 ⬜（PM 除外）
- 每条需求对应一个 Task，粒度为需求级别（粗粒度）
- 每个 Task 必须引用一个 PM 需求文件；禁止为了压缩 Task 标题而删除需求细节
- PM 归档时 `PM` 列标记为 ✅，其余角色标记为 ⬜（或与角色参与计划一致）
- "PM 需求文件"字段：PM 归档时填写，值为 `pm/[name].md`
- "CTO 设计文件"字段：PM 归档时预填为 `cto/[name].md（待产出）`
- "UX 设计文件"字段：UX 参与时预填为 `ux/[name].md（待产出）`；UX 不参与时填 `无`
- 无设计需求时，CTO/UX 对应字段填 `无`

## 状态字段值约定

| 角色 | 字段值 | 含义 |
|------|--------|------|
| CTO / UX | ✅ | 设计完成 |
| CTO / UX | ⏭️ | 跳过，无需设计 |
| CTO / UX | ⬜ | 待处理 |
| DEV / QA | ✅ | 完成 |
| DEV / QA | 🔄 | 进行中 |
| DEV / QA | ⬜ | 待处理 |
