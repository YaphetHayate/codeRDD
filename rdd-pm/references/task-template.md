# Task 模板

## 文件格式

```markdown
# Task Tracker

> 状态说明：✅ 完成 | ⬜ 待开始 | ⏭️ 跳过 | 🔄 进行中

## 总览

| Task | 优先级 | PM | CTO | DEV | QA |
|------|--------|----|-----|-----|----|
| 1. [需求标题] | [优先级] | ✅ | ⬜ | ⬜ | ⬜ |
| 2. [需求标题] | [优先级] | ✅ | ⬜ | ⬜ | ⬜ |

## Task 1: [需求标题]

- **需求来源**：requirement.md > 需求 1
- **优先级**：[优先级]
- **PM**：✅
- **CTO**：⬜
- **DEV**：⬜
- **QA**：⬜

## Task 2: [需求标题]

...
```

## 规则

- 每条需求对应一个 Task，粒度为需求级别（粗粒度）
- PM 归档时 `PM` 列标记为 ✅，其余角色标记为 ⬜
- CTO 字段支持三种值：✅（设计完成）、⏭️（跳过，无需设计）、⬜（待处理）
- DEV 和 QA 字段支持两种值：✅（完成）、⬜（待处理）；如需标记进行中可用 🔄
- 总览表和详情部分保持同步更新
