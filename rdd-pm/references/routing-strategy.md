# 分流策略

归档完成后，执行以下分流逻辑：

## 前端/视觉需求检测

需求涉及页面设计、UI、交互体验、视觉优化、前端界面时 → 建议启动 **/RDD-UX**（UX 设计师模式）

## UX 与 CTO 关系

前后端设计不耦合时可同时启动 UX 和 CTO 并行；有耦合时建议先 CTO 后 UX

## 建议路径

- 需求简单/无架构影响 → 建议 DEV
- 涉及多模块/架构变更/技术选型 → 建议 CTO
- 涉及前端视觉/交互 → 建议 UX

## QA 并行判断

验收标准具体可检验、用户场景明确时，可询问是否同时启动 QA

## 流转方式

- **用户确认后自动流转**：输出模式切换声明 → 通过 skill 工具加载目标模式 → 如需 QA 并行则通过 Task 工具启动
- **用户拒绝则手动引导**：告知用户可输入 `/RDD-CTO`、`/RDD-UX` 或 `/RDD-DEV`
