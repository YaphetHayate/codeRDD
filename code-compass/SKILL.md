# Code Compass — 项目代码理解加速器

## 它解决什么问题

面对陌生项目时，人类开发者和 AI Agent 都需要花费大量时间阅读代码才能回答：
- 项目有哪些模块，各自负责什么？
- 代码的入口在哪，业务流程怎么流转？
- 改一行代码会影响哪些地方？

Code Compass 通过预先构建结构化索引，让这些信息**一次构建、按需查询**，避免反复阅读源码。

## 核心能力

### `/map` — 代码索引构建

扫描项目源码，在 `.code-compass/` 下构建完整的代码索引系统：

| 能力 | 说明 |
|------|------|
| 方法签名索引 | 每个源码文件的函数/方法签名，支持 Python、TypeScript/JavaScript、Java、Go |
| 调用链路图 | 函数级调用关系（A 调用 B），支持正向查询（我调用了谁）和逆向查询（谁调用了我） |
| 入口点导航 | 自动识别 API 路由、定时任务、CLI 命令等入口，生成中文业务摘要 |
| 增量更新 | 基于文件变更检测，只更新变化的部分，不每次全量重建 |

触发命令：`/map`（构建或增量更新）、`/map --refresh`（刷新过期的入口描述）

### `/readme` — README 文档生成

分析项目代码结构，自动生成专业的中文 README.md 文档，包含项目简介、技术栈、目录结构、安装运行步骤、接口说明等。

触发命令：`/readme`

## 生成的产物与使用方式

`/map` 命令在项目根目录生成 `.code-compass/` 索引目录：

```
.code-compass/
├── manifest.json      # 全局索引（文件列表、状态统计）
├── overview.md        # 目录结构概览（人类可读）
├── methods/           # 方法签名（每源码文件一个 JSON）
├── calls/             # 调用关系（每源码文件一个 JSON）
└── entries.json       # 入口点汇总（API 路由 + 定时任务 + CLI）
```

**快速上手路径**：

1. 读 `overview.md` — 了解项目骨架和入口点总览
2. 读 `entries.json` — 按业务关键词定位入口（如"员工"、"订单"）
3. 从入口出发，读 `calls/*.json` — 沿调用链导航到具体函数
4. 读 `methods/*.json` — 查看目标函数的签名和说明

> 数据格式定义和详细查询方式见 `references/map/map.md`。

`/readme` 命令生成 `README.md`（根目录已有 README 时生成 `README-NEW.md`）。

## 路由规则

1. 明确命令（`/readme`、`/map`）→ 直接执行对应功能
2. 自然语言关键词 → 匹配最相关的功能
3. 无法确定 → 向用户确认
4. 匹配到功能后，读取对应参考文件开始执行：
   - `/readme` → `references/readme-generator/readme-generator.md`
   - `/map` → `references/map/map.md`
